## Research

My thesis, *Demystifying Compiler Optimizations: A Reliability Perspective*, examines how compiler optimizations affect the way programs respond to hardware faults.

- **Compiler reliability** — I use LLVM and fault injection to study when faults are masked, cause crashes, or silently corrupt results.
- **Selective fault tolerance** — I’m exploring how compilers can protect selected instructions within a performance budget.
